Dokumentasi Presentasi Project Onyx Residence / KostKu

Topik: Sistem informasi kos/residence berbasis web untuk booking, admin kamar, penghuni, pembayaran, utilitas, laporan, dan chat.

Live URL: https://onyx.nawf.dev/

Stack: Vite Vanilla JavaScript + CSS, PHP Native API, MySQL, Apache/LiteSpeed hosting.

Dokumen ini menjelaskan project sesuai implementasi lokal: lokasi file, CRUD, search, print, command program, dan alur fitur utama untuk bahan presentasi ke dosen.

1. Ringkasan Project

Onyx Residence adalah aplikasi manajemen kos/residence. Aplikasi memiliki halaman publik untuk calon penghuni, portal penghuni untuk status pendaftaran dan pembayaran, serta admin panel untuk mengelola kamar, penghuni, bukti pembayaran, meter utilitas, layanan, laporan keuangan, dan chat grup.

  • Public page: landing page dan booking/register calon penghuni.
  • Resident portal: login penghuni, invoice, upload bukti, utilitas, layanan, access, chat.
  • Admin panel: dashboard, CRUD kamar, data penghuni, payment detail, utility meter, laporan, chat.
  • Backend: REST-like API PHP native dengan PDO MySQL, auth, CSRF, upload proof, dan response JSON.

3. Teknologi yang Digunakan

  • Frontend: Vite, JavaScript module, HTML template, CSS custom tanpa framework UI.
  • Backend: PHP native, PDO MySQL, JSON API.
  • Database: MySQL, tabel utama seperti resident_applications, kamar, payment_proofs, utility_meters, service_tickets, group_chat.
  • Security: session/cookie auth, Basic admin fallback, CSRF header X-CSRF-Token, CORS, upload MIME check, rate limit.
  • Deploy: build Vite lalu upload dist dan backend PHP ke hosting.

5. Arsitektur Alur Sistem

  1. User membuka public page lalu melakukan booking/register.
  2. Frontend mengirim data ke API be/api/resident-application.php.
  3. Admin login melalui be/api/admin-auth.php.
  4. Admin panel mengambil state gabungan dari be/api/admin-state.php.
  5. Admin mengelola kamar, penghuni, bukti pembayaran, meter utilitas, laporan, dan chat.
  6. Resident portal membaca status aplikasi, invoice, upload bukti, dan chat via API.

9. Penjelasan Fitur Utama Admin

Dashboard

Dashboard menampilkan KPI pendapatan, kamar terisi/kosong, chart pendapatan 6 bulan, occupancy, penghuni terbaru, dan transaksi terbaru. Fungsi utama ada di renderDashboard().

Menu Kamar

Menu Kamar menampilkan daftar kamar dengan search, filter tipe/status, tambah/edit/hapus kamar, detail kamar, smart control, meter utilitas, dan cetak laporan kamar. Data server diambil dari kamar.php.

Menu Penghuni

Menu Penghuni menampilkan list penghuni dan penyewa. Fitur baru: search nama/kamar/kontak/NIK dan cetak detail identitas. Hapus penghuni tidak menghapus fisik langsung, tetapi menandai status Dibatalkan supaya aman dan tidak muncul lagi di admin state.

Menu Pembayaran

Payment Detail dirapikan menjadi sidebar buyer, tab Ringkasan, Metode Bayar, dan Bukti Masuk. Admin dapat melihat status, total tagihan, QRIS, transfer manual, dan approve/reject bukti.

Menu Laporan

Laporan keuangan menampilkan transaksi, pemasukan, outstanding, deposit, dan tagihan utilitas tercatat. Catatan penting: tagihan utilitas sekarang tidak dikurangi dari omset karena dalam konteks project biaya tersebut adalah data meter/tagihan penghuni, bukan otomatis beban pemilik kost.

10. API Backend Penting

  • be/api/admin-auth.php: login admin.
  • be/api/admin-state.php: agregasi data admin panel.
  • be/api/resident-application.php: pendaftaran dan status penghuni.
  • be/api/kamar.php: CRUD kamar.
  • be/api/payment-proof.php: upload/review bukti pembayaran.
  • be/api/payment-create.php: membuat pembayaran QRIS.
  • be/api/utility-meter.php: catatan listrik/air.
  • be/api/service-ticket.php: tiket layanan penghuni.
  • be/api/chat.php: chat grup admin-penghuni.

11. Keamanan

  • Endpoint admin dilindungi Auth::requireAdmin().
  • Request mutasi data memakai CSRF via X-CSRF-Token.
  • Upload bukti pembayaran dibatasi ukuran dan MIME type.
  • Response API memakai JSON konsisten.
  • Frontend menggunakan escapeHtml() untuk menghindari injection pada data yang dirender.

12. Kesimpulan

Project Onyx Residence sudah mencakup alur bisnis kos dari pendaftaran sampai manajemen admin. Bagian yang bisa ditunjukkan saat presentasi: public booking, login admin, CRUD kamar, search penghuni, payment detail, review bukti, catat meter utilitas, laporan print, dan chat grup. Project ini menunjukkan integrasi frontend, backend API, database, autentikasi, upload file, dan UI admin yang siap dipakai untuk operasional kos.
